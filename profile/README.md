# Auckland Hackathons

Repositories for civic hackathons in Auckland.

## Auckland CivicTech Hackathon · Friday 16 October 2026

A one-day build with Auckland Council, run by Creative HQ as part of Auckland
Startup Week. Six teams each take a problem statement from Council (transport,
flood resilience or waste) and build a working prototype in a day.

| Repository | What |
|---|---|
| [akl.civic.hack.2026-10-16](https://github.com/Auckland-Hackathons/akl.civic.hack.2026-10-16) | Event overview, problem statements, schedule |
| [akl-civic-data](https://github.com/Auckland-Hackathons/akl-civic-data) | Public data catalogue for the problem statements, with Python and JavaScript clients |
| `akl.civic.hack.team-1.2026-10-16` to `team-6` | One repository per team; each is that team's submission |

Repositories are private while the event is being prepared.
